# Strategic Focus Engine — Release Notes v1.0

## Что это

Модификация бота-планера, которая **перенаправляет Hooked-цикл на стратегически важные задачи**. Вместо того чтобы тратить 8 часов на vibe coding 38 несвязанных проектов — бот создаёт такой же дофаминовый цикл, но направленный на стратегические цели.

## Проблема, которую решаем

```
Fun-проекты:    Низкий порог → Быстрый фидбек → Variable reward → Гештальт → 8 часов пропало
Стратегия:      Высокий порог → Отложенный фидбек → Нет reward → Буксует
```

## Архитектура решения

### Новые файлы

| Файл | Размер | Что делает |
|------|--------|-----------|
| `strategic_data.py` | ~280 строк | Модель данных: цели, квесты, задачи, XP, уровни, gate, гештальты. Хранит всё в `strategic_goals.json` |
| `strategic_prompts.py` | ~220 строк | 17 стартовых промптов по 4 целям, LARP-нарратив (40+ фраз), типы задач |
| `strategic_engine.py` | ~300 строк | Движок: gate-механизм, гештальт-менеджер, novelty engine, декомпозиция, утренний брифинг |

### Изменения в существующих файлах

- **`bot.py`** — 9 новых команд, 5 новых conversation states. Исправлены баги: дубль `daily_reminder`, отсутствующий handler у `SET_TIME`
- **`prompts.py`** — добавлены стратегические цели в категории, ChatGPT маркирует активности привязкой к целям

## 6 психологических механизмов

### 1. Снижение порога входа (`/focus`)
**Проблема:** Стратегическую задачу сложно начать — непонятно что делать первым.
**Решение:** 17 готовых стартовых промптов на 20-60 минут. Выбрал номер — получил конкретную инструкцию.

```
🚀 Готовые стартовые задачи (выбери номер):

1. 🏢 🔍 Экспресс-аудит воронки продаж
   30-60 мин  |  +15 XP

2. 🤖 🔨 Черновик программы воркшопа
   60 мин  |  +20 XP

3. 💡 💬 Пост в «Хороший Вопрос»
   30 мин  |  +15 XP
```

### 2. Fast feedback loop (XP + LARP)
**Проблема:** Стратегическая работа не даёт немедленного удовлетворения.
**Решение:** Каждая задача = XP. 8 уровней от «Стратег-новичок» до «Властелин фокуса». LARP-нарратив при завершении.

```
⚡ Прогресс! Ещё один шаг к цели. +15 XP

⚔️ Архитектор роста (ур. 3) | XP: 285
🔥 Серия 5 дней подряд! Momentum нарастает.
```

### 3. Task switching management
**Проблема:** Когда один проект «думает» — переключаешься на fun.
**Решение:** После записи активностей бот предлагает следующую задачу ИЗ СТРАТЕГИЧЕСКОГО БЭКЛОГА:

```
⏳ Пока ждёшь результат — вот задача из стратегического бэклога:

🏢 Рост JetStyle 2026 → Аудит воронки продаж
📋 Следующий шаг: Найти 3 самых узких места в воронке
Прогресс квеста: 20%
```

### 4. Gate-механизм (`/fun`)
**Проблема:** Fun-проекты всегда доступны и перетягивают внимание.
**Решение:** 2 стратегических задачи → 1 fun разрешён. После fun — снова нужно 2 стратегических.

```
🔒 До fun-режима: ещё 1 стратегических задач (1/2)
  или
🟢 Fun-режим разблокирован! (выполнено 2/2 стратегических задач)
```

### 5. Гештальт-менеджмент (Зейгарник)
**Проблема:** Гештальты открыты для fun-проектов, не для стратегии.
**Решение:** Бот намеренно создаёт незавершённые стратегические задачи и напоминает о них:

```
📌 Незавершённый гештальт (Рост JetStyle 2026):
«Аудит воронки продаж: Найти 3 узких места» — прогресс 40%
Хочешь закончить?
```

### 6. Novelty внутри фокуса
**Проблема:** Стратегические задачи кажутся однообразными.
**Решение:** 4 типа задач (🔍 анализ, 🔨 прототип, 💬 коммуникация, 📚 исследование) + случайные ракурсы с 30% шансом:

```
💡 Мысль: Как бы выглядел MVP этого за 1 день?
```

## Исправленные баги в оригинальном коде

1. **Дубль `daily_reminder`** — было две функции с одним именем (строки 341 и 383), вторая перезаписывала первую. Оставлена одна корректная.
2. **`SET_TIME` handler без callback** — `MessageHandler(filters.TEXT & ~filters.COMMAND,)` — запятая без второго аргумента. Теперь вызывает `save_time`.
3. **Первая `daily_reminder` ссылалась на `update`** — которого нет в сигнатуре callback-функции job queue.
